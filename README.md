# Caminos del Tigre · Prototipo 2

Sitio institucional multipágina desarrollado en HTML, CSS y JavaScript sin dependencias.

## Arquitectura

- `index.html`: inicio y rutas diferenciadas por público.
- `programa.html`: presentación, beneficiarios y beneficios.
- `territorio.html`: cobertura, infraestructura y fotografías.
- `como-funciona.html`: siete etapas en paneles interactivos.
- `ayuda.html`: preguntas frecuentes y cartilla de usuario.
- `contacto.html`: canales y enlaces institucionales.

## Imágenes oficiales

La carpeta `assets/imagenes-oficiales/` está reservada para las fotografías autorizadas que se reciban posteriormente. Su archivo `README.md` contiene nombres y proporciones recomendadas.

## Ejecución local

```powershell
python -m http.server 4175
```

Abrir `http://localhost:4175/`.
